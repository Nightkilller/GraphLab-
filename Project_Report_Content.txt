GRAPHLAB: PROJECT OVERVIEW & CAPABILITIES

PART 1: WHAT IS THIS PROJECT?

GraphLab is an interactive, browser-based digital laboratory designed for learning and analyzing Discrete Mathematics and Graph Theory algorithms. 

Key Aspects:
• Visual Learning Platform: It replaces static textbook diagrams with a hands-on, drag-and-drop canvas where users can draw custom graphs, test theoretical invariants, and watch algorithms execute step-by-step in real time.
• 100% Offline & Local Execution: Built with TypeScript and React 19, GraphLab runs entirely on the user's local CPU inside the browser. It requires zero servers, zero cloud databases, and zero internet connection, guaranteeing instant computation, zero latency, and complete privacy.
• Multi-Engine Rendering: Features interactive 2D SVG vector rendering, high-performance HTML5 Canvas, and full 3D spatial representations.


PART 2: WHAT CAN IT DO?

GraphLab provides a comprehensive suite of practical graph theory tools:

1. Two-Graph Isomorphism Solver (G₁ ≅ G₂):
   • Automatically detects two separate graphs drawn side-by-side on the canvas.
   • Checks graph invariants (orders |V|, sizes |E|, degree sequences).
   • Computes the exact structure-preserving bijection mapping (π: V₁ → V₂).
   • Generates randomized isomorphic "twin" graphs to test equivalence.

2. Graph Theory & Mathematical Solvers:
   • Havel-Hakimi Theorem: Validates degree sequences and renders valid graphs.
   • Bipartite Verification: Performs 2-coloring checks and rearranges graphs into clean two-column partition layouts or highlights odd-cycle counterexamples.
   • Complement Graphs (G'): Computes graph complements and verifies |E(G)| + |E(G')|.
   • Matrix Generator: Exports Adjacency and Incidence matrices with one click.

3. Step-by-Step Algorithm Visualizers:
   • Shortest-Path Pathfinding: Interactive Dijkstra and Bellman-Ford algorithms with negative weight and cycle support.
   • Full Playback Control: Step forward/backward, pause, timeline scrubbing, and adjustable speed (0.25x–4x).

4. Canvas & Export Tools:
   • Marquee selection to bulk-move or delete nodes, floating text tool for math notes, pre-built graph templates (Cycles, Paths, Complete Kₙ), and high-resolution SVG/PNG image export for reports.
