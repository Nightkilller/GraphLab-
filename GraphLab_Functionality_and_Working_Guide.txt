GRAPHLAB: HOW EACH FEATURE WORKS

1. Two-Graph Isomorphism (G₁ ≅ G₂)
• What it is: Checks if two different-looking graphs have the exact same structure.
• How it works:
  - First tests if vertex counts, edge counts, and degree sequences match.
  - Runs a backtracking search to find the exact node mapping (e.g., A→2, B→4).
  - Can also generate an isomorphic "twin" with randomized node labels to test.

2. Havel-Hakimi Theorem (Degree Sequences)
• What it is: Tests if a list of numbers (degrees) can form a real, valid graph.
• How it works:
  - Repeatedly removes the largest degree and subtracts 1 from the next nodes.
  - If it reduces to all zeros, it is valid and draws the graph on canvas.
  - If any negative number appears, the degree sequence is impossible.

3. Bipartite Graph & 2-Coloring
• What it is: Tests if nodes can be divided into 2 sets where no two connected nodes share the same color (no odd-length cycles).
• How it works:
  - Uses BFS to alternate node colors (Red and Blue).
  - If valid, rearranges the graph into 2 neat vertical columns.
  - If invalid, highlights the odd-length cycle that breaks the rule.

4. Complement Graph (G')
• What it is: A graph with the same nodes, but connects edges where NONE existed.
• How it works:
  - Finds all missing edges and builds the inverted graph.
  - Shows original G and complement G' side-by-side to compare.

5. Adjacency & Incidence Matrices
• What it is: Represents graph connections in standard mathematical grid tables.
• How it works:
  - Adjacency Matrix: Node-by-node grid showing edge connections/weights.
  - Incidence Matrix: Node-by-edge grid showing which node touches which edge.
  - Includes a 1-click button to copy directly into Word or Excel.

6. Step-by-Step Algorithm Visualizers
• What it is: Animates graph pathfinding algorithms node-by-node.
• How it works:
  - Supports shortest-path pathfinding via Dijkstra and Bellman-Ford algorithms.
  - Uses generator functions to pause at each step, showing visited nodes, distance updates, and queue state with full playback controls.

7. Interactive Canvas Tools
• How it works:
  - Double-click to add nodes, drag between nodes to connect edges.
  - Click any edge to change weights or toggle between directed and undirected.
  - Box Select tool (B) to move/delete groups, and Text tool (T) to add math notes.
